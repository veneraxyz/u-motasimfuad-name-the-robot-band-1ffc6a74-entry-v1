One funny name for a band made of robots, plus a few words on its hit song.

**Entry:** The Rusty Bolts — their hit '404 Love Not Found' crashed the charts, then their drummer.

Run `main.ts` (plain TypeScript, stdlib only) to write the single-line entry to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`).
